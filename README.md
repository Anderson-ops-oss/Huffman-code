# Huffman Code Project
This project implements the Huffman coding algorithm for efficient encoding and decoding of messages. Huffman coding is widely used in areas such as cybersecurity and algorithm design due to its ability to compress data effectively.

## Project Structure ##
The project consists of three Python scripts:
* huffmanCode.py: A comprehensive implementation of the Huffman coding algorithm with detailed explanations. This script is ideal for learning and understanding the algorithm.
* huffmanCodeEncode.py: A script dedicated to encoding messages using Huffman coding.
* huffmanCodeDecode.py: A script dedicated to decoding messages encoded with Huffman coding.

You can modify the contents of input.txt to test different encoded messages.

## How to Run ##
### Encoding and Learning ###
To run the main Huffman coding implementation and encoding script:
```
python huffmanCode.py input.txt
```
### Decoding ###
To run the decoding script:
```
python huffmanCodeDecode.py
```

## Usage ##
* huffmanCode.py: This script provides a step-by-step explanation of the Huffman coding process. It reads the input from input.txt, encodes the message, and displays the encoded output along with the Huffman tree.
* huffmanCodeEncode.py: Use this script to encode messages. It reads the input from input.txt and outputs the encoded message.
* huffmanCodeDecode.py: Use this script to decode previously encoded messages. It reads the encoded message and the Huffman tree from the output of the encoding process and reconstructs the original message.
